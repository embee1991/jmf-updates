# JMF – Desktop-Updates

Hier erscheinen bewusst freigegebene Versionen von JMF für Windows sowie Apple-Silicon- und Intel-Macs.

Fertige Downloads findest du unter **Releases**. Neue Versionen werden in JMF unter **Einstellungen → Updates** angezeigt. Entwürfe und Testpakete sind keine veröffentlichten Updates.

Dieses Repository enthält ausschließlich Hinweise und fertige App-Pakete. Der App-Quellcode bleibt privat. Filmdaten, Bewertungen, Profile und Zugangsdaten werden hier nicht gespeichert.
